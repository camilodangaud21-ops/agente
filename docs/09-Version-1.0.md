- [x] Gemma
- [x] Image Agent
- [x] Audio Agent

- [x] Report Agent
- [x] PDF Service
- [x] Knowledge Agent
- [x] Graph Service

- [x] Extracción de relaciones
- [x] Grafo de conocimiento

La versión 1.0 permite transformar información multimodal en conocimiento estructurado y representarlo mediante un grafo.
