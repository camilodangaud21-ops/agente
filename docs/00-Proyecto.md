# Agente Multimodal

## Descripción

Agente multimodal desarrollado con Python, Ollama y Gemma, capaz de procesar información proveniente de imágenes y audio.

El sistema transforma la información obtenida en estructuras JSON, integra los resultados, genera informes y construye un grafo de conocimiento.

## Tecnologías

- Python
- Ollama
- Gemma 3 4B
- Whisper
- NetworkX
- ReportLab
- JSON
- GraphML

## Objetivo

Construir un sistema basado en agentes capaz de transformar información multimodal en conocimiento estructurado.

## Versiones

### V1.0

Procesamiento multimodal, generación de informes y construcción de grafos de conocimiento.

### V2.0

Interacción mediante comandos de voz y orquestación de agentes.
